## 1. 产品概述
一款基于 AI 图像生成 API 的在线创作工具，支持文生图和图生图两种模式，让用户通过自然语言描述即可快速生成高质量图片。
- 解决设计师、内容创作者快速获取 AI 生成图片的需求，降低创作门槛
- 面向创意工作者和普通用户，提供简洁直观的 AI 绘图体验

## 2. 核心功能

### 2.1 功能模块
1. **创作页面**：文生图输入、图生图上传、参数配置、图片生成与展示

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 创作页面 | 模式切换 | 文生图/图生图 Tab 切换 |
| 创作页面 | 文生图面板 | 自然语言输入框、生成按钮 |
| 创作页面 | 图生图面板 | 图片上传区域、提示词输入、生成按钮 |
| 创作页面 | 参数配置 | 图片尺寸选择（正方形/横版/竖版） |
| 创作页面 | 生成结果展示 | 图片预览、下载按钮、生成历史缩略图 |
| 创作页面 | 历史记录 | 侧边栏展示最近生成的图片缩略图，点击可查看大图 |

## 3. 核心流程

用户打开页面 → 选择模式（文生图/图生图）→ 输入提示词（图生图还需上传参考图）→ 选择尺寸 → 点击生成 → 等待生成 → 预览结果 → 下载图片

```mermaid
flowchart TD
    "A[用户打开页面]" --> "B[选择模式]"
    "B" --> "C[文生图]"
    "B" --> "D[图生图]"
    "C" --> "E[输入提示词]"
    "D" --> "F[上传参考图 + 输入提示词]"
    "E" --> "G[选择图片尺寸]"
    "F" --> "G"
    "G" --> "H[点击生成]"
    "H" --> "I[调用 API 生成图片]"
    "I" --> "J[展示生成结果]"
    "J" --> "K[下载/继续创作]"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色背景（#0a0a0f）+ 霓虹紫蓝渐变强调色（#7c3aed → #06b6d4）
- 按钮：圆角胶囊按钮，hover 时发光效果
- 字体：标题使用 Outfit，正文使用 DM Sans
- 布局：左右分栏，左侧创作面板，右侧结果展示
- 图标风格：线性图标，带微光效果

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 创作页面 | 模式切换 | Tab 切换，带滑动指示器动画 |
| 创作页面 | 文生图面板 | 大面积输入框，placeholder 带示例提示词 |
| 创作页面 | 图生图面板 | 拖拽上传区域，虚线边框，支持粘贴 |
| 创作页面 | 参数配置 | 尺寸选择卡片组，选中态带渐变边框 |
| 创作页面 | 生成结果 | 居中大图预览，底部下载按钮，加载时脉冲动画 |
| 创作页面 | 历史记录 | 底部横向滚动缩略图条 |

### 4.3 响应式
- 桌面优先，移动端自适应为上下布局
